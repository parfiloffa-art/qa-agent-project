# Кредитный калькулятор «Банк Прикола»

## Что сделано

Одностраничный кредитный калькулятор на чистых HTML, CSS и JavaScript.

- аннуитетные и дифференцированные платежи;
- автоматический пересчёт и сравнение схем;
- валидация суммы, ставки и срока;
- помесячный график дифференцированных платежей;
- адаптивный интерфейс для мобильных и широких экранов.

## Как запустить

В папке проекта выполните:

```bash
python3 -m http.server 8765
```

Затем откройте в браузере:

```text
http://localhost:8765
```

Установка зависимостей и подключение к интернету не требуются.
