# Объединённый набор сценариев для поля «Годовая процентная ставка»

## Общая фикстура

- сумма кредита: `100000 ₽`;
- срок: `12` месяцев;
- тип платежей: аннуитетный;
- если сценарий явно не проверяет начальное состояние, изменяется только поле годовой процентной ставки;
- не проверяются конкретные денежные значения, график, адаптивность, сумма кредита и срок.

## Форматы значения

### IR-FMT-02 — Ставка с точкой как десятичным разделителем принимается

- **Проверяемое требование:** `SPEC.md`, раздел «Годовая процентная ставка»: точка и запятая принимаются как десятичные разделители; `12.5` означает `12,5%`.
- **Источник:** Formats.
- **Предусловия:** сумма `100000`, срок `12` месяцев и аннуитетный тип платежей установлены; поле ставки пустое; результаты скрыты.
- **Тестовые данные:** `12.5`.
- **Краткие шаги:** ввести `12.5` в поле ставки и завершить ввод.
- **Точный ожидаемый результат:** значение принимается как корректное; под полем ставки нет сообщения об ошибке; подробный и сравнительный блоки отображаются автоматически.
