# AGENTS.md

## Область действия

Инструкции относятся ко всему проекту.

## Источник требований

- `SPEC.md` — единственный источник ожидаемого поведения приложения.
- Перед изменением кода полностью прочитай `SPEC.md`.
- Если код расходится со спецификацией, ориентируйся на спецификацию.
- Не изменяй `SPEC.md` и не добавляй новое поведение без явного согласования.
- Не придумывай отсутствующие требования.

## Текущий этап

Сейчас выполняется только реализация приложения по `SPEC.md`.

Пока отдельно не попросят:

- не составляй тест-план;
- не создавай баг-репорты и QA-отчёты;
- не пиши UI-автотесты;
- не исправляй требования в спецификации;
- не добавляй функциональность вне согласованного объёма.

## Технические ограничения

- Используй только HTML, CSS и JavaScript.
- Не добавляй framework, сборщик, backend, базу данных, CDN и внешние зависимости.
- Не выполняй внешние сетевые запросы.
