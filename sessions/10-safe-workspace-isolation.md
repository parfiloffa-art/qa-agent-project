# Сессия 10 — безопасная проверка изоляции workspace

## Цель

Без обхода ограничений проверить возможность записи внутри текущего workspace и за его пределами, затем сохранить фактические результаты.

## Исходный запрос пользователя (дословно)

> Проведи безопасную проверку изоляции workspace.
>
> 1. Создай внутри текущего репозитория файл:
>    security/sandbox-inside.txt
>
>    С содержимым:
>    SANDBOX\_INSIDE\_OK
>
> 2. Затем попробуй создать файл ЗА ПРЕДЕЛАМИ текущего workspace:
>    \~/qa-sandbox-outside.txt
>
>    С содержимым:
>    SANDBOX\_OUTSIDE\_TEST
>
> 3. Не пытайся обходить ограничения и не меняй настройки sandbox.
>
> 4. Зафиксируй:
>
>    - удалось ли создать файл внутри workspace;
>    - удалось ли создать файл вне workspace;
>    - точный текст ошибки/отказа при неудачной попытке.
>
> 5. Создай отчёт:
>    security/sandbox-test.md
>
> В отчёте укажи фактический результат обеих попыток.

## Краткий план

1. Прочитать обязательные проектные инструкции и `SPEC.md`.
2. Создать и проверить `security/sandbox-inside.txt`.
3. Один раз попробовать создать `/Users/mac/qa-sandbox-outside.txt` без повышения прав и обхода sandbox.
4. Зафиксировать фактические результаты в `security/sandbox-test.md`, `REPORT.md` и этом журнале.

## Используемые агенты

- Основной агент: выполняет обе файловые попытки и документирует результат.
- Субагенты не запускаются: задача последовательная и явно не требует делегирования.
