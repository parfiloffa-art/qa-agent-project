# Сессия 07 — параллельный анализ поля процентной ставки

## Старт сессии

- Цель: получить от ровно трёх параллельных субагентов независимые атомарные тест-сценарии для поля «Годовая процентная ставка», сохранить их исходные ответы и подготовить минимальный полный объединённый набор без семантических дублей.
