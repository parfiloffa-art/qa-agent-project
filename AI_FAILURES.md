# Ошибки нейросети

В этом файле фиксируются подтверждённые ошибки нейросети во время работы над
проектом.

## 2026-08-27 — неверно указан путь к тест-плану в README

**Ошибочное утверждение:** нейросеть сообщила, что `README.md` указывает на
`docs/TEST_PLAN.md`, и на этом основании предложила согласовать расположение
тест-плана.

**Фактическое состояние:** в текущем `README.md` указан корневой файл
`TEST_PLAN.md`.

**Исправление:** каноническим файлом принят
`/Users/mac/Desktop/qa-agent-project/TEST_PLAN.md`. Нейросеть признала ошибку:
«Вы правы: в текущем `README.md` указан корневой `TEST_PLAN.md`. Моя предыдущая
ссылка на `docs/TEST_PLAN.md` была ошибочной».

**Последствие:** пользователю был задан лишний уточняющий вопрос о расположении
тест-плана.
