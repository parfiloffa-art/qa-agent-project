- Третий узкий прогон выявил lifecycle-гонку между асинхронным завершением HTTP-сервера предыдущего Maven-процесса и навигацией нового Chrome (`net::ERR_CONNECTION_REFUSED`). Новый класс теперь повторно проверяет доступность приложения непосредственно перед навигацией и запускает сервер только при необходимости.

- Финальный полный прогон: `mvn test`; выполнены `TcCalc001Test` и `TcTerm001Test`; `Tests run: 2, Failures: 0, Errors: 0, Skipped: 0`; `BUILD SUCCESS`; `4.352 s`.
